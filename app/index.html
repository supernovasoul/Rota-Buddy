Weekly availability pattern

The usual working pattern for each person - the starting template the month grid below is pre-filled from. Someone with nothing set yet is available every day (and every slot) by default. Receptionists: tick Early/Later/Full for each weekday (Full only on weekends). Therapists: just tick the days they work - which length shift they actually do each day is set separately, in Settings › Shift types.
